# KaracaLab website

Source of https://csb-karacalab.github.io/ — the Computational Structural Biology Lab at the Izmir Biomedicine and Genome Center (IBG).

The whole site is one self-contained page, `index.html` (styles, scripts, team photos and the protein figure data are inline). Edit it and push to `main`; GitHub Pages republishes within a minute or two.

- `og-image.png`: 1200×630 preview shown when the link is shared
- `favicon-32.png`, `apple-touch-icon.png`: browser and home-screen icons
- `.nojekyll`: serve files as they are, without Jekyll processing
